# Employee HRMS

A beginner-friendly Employee Human Resource Management System built with Flask and PostgreSQL.

## Features

- User Registration & Login
- Password Hashing
- JWT-based API Authentication
- Employee Management
- Add & View Employees
- PostgreSQL Database Integration
- REST API
- Docker configuration

## Tech Stack

- Python
- Flask
- PostgreSQL
- Flask-JWT-Extended
- Docker
- Git & GitHub

## Project Status

This is my first backend project, created to learn and practice real-world backend development concepts.
